# Roach Smash: You vs Mom

A 30-second browser game. You and Mom, one house, whoever smashes the most roaches wins.

Play it: https://victoria-yaqing-yang.github.io/roach-smash/

## The story

When I was a kid my family lived on one salary in an apartment with a lot of cockroaches. My mom turned it into a game: every month, a competition over who killed more. I didn't find roaches disgusting until much later. As a kid, it was just the game we played.

I told that story over dinner. The next day I got an email with an HTML file and one line: "Open it in your browser."

This is that file.

## Running it

It's a single `index.html` with no dependencies beyond two Google Fonts. Open it in any browser, or serve the folder with any static host.
